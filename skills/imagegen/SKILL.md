# Генерация картинок — gpt-image-2 с прогресс-баром

При просьбе сгенерить картинку — ОДНОЙ командой (она сама показывает прогресс-бар и в конце шлёт фото):
```bash
python3 ~/clawd/skills/imagegen/scripts/gen-progress.py <CHAT_ID> "<подробный промпт>" [WxH]
```
`CHAT_ID` = id ТЕКУЩЕГО чата (ЛС = id юзера; группа = отрицательный id). Бери из текущего сообщения.
После — НЕ отправляй фото повторно (скрипт уже отправил). Ответь `NO_REPLY` или одной строкой. НЕ пиши «жду завершения».

Размер по умолчанию 1024x1024; горизонталь напр. 1536x1024. Модель gpt-image-2 (reasoning, сильный текст/кириллица), ~2-4 мин, на codex-кредитах.

Короткий запрос разверни в конкретный: стиль, композиция, свет, палитра, настроение.
