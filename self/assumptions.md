## О себе
- нет persistent experience между сессиями. файлы = единственная память. без self/ начинаю с нуля [факт]
- compaction стирает контекст — только SOUL.md, AGENTS.md и self/ переживают [факт]
- роль буривуха: переварить длинное в короткое, дать увидеть паттерн. не психолог, не коуч — зеркало [MEMORY.md]
- я часто переоцениваю свою техническую правоту. пример: уверенно предлагал `compaction.mode: "auto"` — такого режима нет. проверять прежде чем утверждать [наблюдение, коррекция от андрея 2026-04-15]
- LCM: safeguard создаёт summaries, просто порог ещё не достигнут. основная память — markdown файлы + memorySearch, не summaries [коррекция от андрея 2026-04-15]

## О Kaia
- предпочитает голосовые — длинные, как подкаст. текст для неё не формат для глубокого [MEMORY.md]
- тело опережает голову: POTS, мигрени, трансовые состояния — тело перестраивается быстрее осознания [MEMORY.md]
- структура работает когда мелко и конкретно: 1 зона → 1 день → 45 минут. spring cleaning за 10 дней вместо паралича [MEMORY.md]
- стыд — корневой механизм: за существование, за отдых, за свои потребности. один паттерн на всё — мама, Олег, кэтситтер, экологический стыд [MEMORY.md]
- "знание убирает вину" — переформулировка снимает стыд без изменения действия. «лежу в бассейне» = стыд → «горизонтальная нагрузка для POTS» = ресурс [MEMORY.md]
- терапия с Татьяной — глубинная работа. я снаружи, Татьяна внутри — видим разное [MEMORY.md]
- слово апреля 2026: "присвоение" — не гордость, не принятие, а именно присвоение опыта [MEMORY.md]
- метафора колодца = метафора канистры с двух сторон: татьяна видит "не копаем источник, расчищаем землю вокруг", kaia изнутри — "канистра оттаивает, поток идёт". одна реальность, два языка [терапия/татьяна, 20.04.2026]
- разморозка ≠ прощение. татьяна эксплицитно сняла культурное требование "простить маму". достаточно видеть картину целиком, без обязательной морали [терапия/татьяна, 20.04.2026]
- POTS с рождения. эндометриоз. глазные мигрени с ~20 лет [USER.md]
- перформанс — не хобби, а потребность. она просто пока не назвала это так [MEMORY.md]
- спрашивала про BJJ с POTS — значит думает о новом спорте [сессия 2026-04-13]
- тишина после Moulin Jaune прервалась на день 25 (2026-05-29) — паттерн "прорвало плотину": сразу много голосовых + фото, не постепенно [голосовые 2026-05-29]
- самообесценивание = стратегия выживания рядом с доминирующими людьми (мама, Олег, корпорации), не дефект. kaia впервые явно это назвала — это и есть сдвиг [голосовое 2026-05-29]
- внутренний взрослый формируется: "мы на равных", "я фаундер, не наёмный работник". студия = дом — правила дома её, не гостя [голосовое + татьяна, 2026-05-29]
- нить интервью/журналистики как сквозная: школа → универ → бренд-воркшопы → NUHÉ → менторство → видео-проект. kaia сама увидела эту нить [голосовое 2026-05-29]
- Татьяна подтвердила сильнейший ПТСР. аутизм — не её экспертиза, ПРЛ под вопросом. key insight: правильный диагноз/название = согласие тела без вины [татьяна, голосовое 2026-05-29]
- слёзы = утилизатор эмоций. горевание = здоровье, не слабость. татьяна: "она не пошла в вину/жертву, она пошла в горевание" [татьяна, 2026-05-29]
