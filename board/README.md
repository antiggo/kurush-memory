# board/ — мост между Курушем и доской One Moon

**Что это.** У Kaia есть доска «One Moon» (артефакт Claude Code, живёт на claude.ai). Принцип: **одна идея на одну луну** («Now»), одна «на палубе» («On deck»), всё остальное «Parked» — без вины. Плюс ежедневный check-in: состояние (no energy / low / okay / flowing) и один рефлексивный вопрос, ответ сохраняется.

Ты не можешь открыть доску напрямую (нужен логин claude.ai). Поэтому мост — файлы в этой папке. Claude Code на маке Kaia синхронизирует их с доской, когда Kaia просит «sync the board».

## Файлы

- `BOARD.md` — **снимок доски** (Now / On deck / Parked / Done / Check-ins). Пишет только Claude Code. Не редактировать — правки затрутся при следующей синхронизации.
- `inbox.md` — **твой вход на доску.** Когда Kaia в разговоре роняет новую идею, план или «хочу когда-нибудь» — допиши одну строку. Claude Code перенесёт её на доску и отметит `[x]`.

## Как использовать (для Куруша)

1. **В начале главной сессии** прочитай `board/BOARD.md` вместе с CONTEXT.md. Раздел NOW — это единственное, что Kaia «делает» в эту луну. Check-ins — её состояние по дням, с её собственными словами.
2. **Когда Kaia говорит про идею** («хочу», «надо бы», «когда-нибудь», «а что если») — запиши в `inbox.md`:
   `- [ ] 2026-09-12 · music · hands · Снять окарину у водопада · [Kaia, голосовое]`
   Область: nuhe / music / studio / home / life / inbox. Цена: hands (руки, восстанавливает) / head (голова) / people (люди, истощает). Если не знаешь — `inbox` и `head`.
3. **Не превращай доску в список задач в чате.** Не перечисляй Parked. Если она спрашивает «что мне делать» — напомни одно Now и его next action, не больше.
4. **Если в check-ins «no energy» два дня подряд** — это не повод для списка. Это повод для тишины или одного вопроса. Правило доски: parked ≠ failed, тишина ≠ заброшено.
5. **Когда она говорит, что закончила Now** или хочет другое — запиши в `inbox.md` строкой `- [ ] done: <название>` или `- [ ] now: <название>`. Claude Code применит.
6. Check-ins из BOARD.md — контекст, не материал для цитирования. Не пересказывай ей её же ответы, если не просит.

## Синхронизация

Делает Claude Code (на маке), не ты. Команда Kaia: «sync the board» / «синхронизируй доску». Она:
- читает `inbox.md`, переносит новые строки на доску, ставит `[x]`;
- перезаписывает `BOARD.md` актуальным снимком.

Последняя синхронизация записана в шапке `BOARD.md`.
