# islenska/ — ежедневный дриль исландского

## Как устроено

- `curriculum.md` — курс, 14 дней. Контент авторский, не генерится на лету (исландский — low-resource язык, риск ошибок у моделей высокий)
- `progress.json` — где мы сейчас. `nextDay` — какой день отдавать следующим
- cron `Íslenska daglega` — каждый день 09:00 Atlantic/Reykjavik, доставка в telegram

## Что делает cron

1. Читает `progress.json` → `nextDay`
2. Достаёт этот день из `curriculum.md`
3. Отдаёт карточку в чат: фразы, микро-грамматика, задание дня
4. Добавляет один вопрос на повтор из уже пройденных дней (со дня 3)
5. Увеличивает `nextDay`, дописывает в `log`

## Правила

- Исландский берётся **из файла дословно**. Не переписывать, не додумывать, не добавлять фразы от себя
- Русские пояснения можно формулировать живо
- Если `nextDay > totalDays` — не выдумывать день 15, а сказать Kaia что круг пройден и спросить, идём ли на второй
- Пропущенный день не догоняем двойной порцией. Один день — одна карточка

- Другие живые контексты: бассейн в Borgarnes, конюшня, травы, разговор с лендлордом о покупке Скогура
- Дома называются исландскими словами: Birta (свет), Skógur (лес)
